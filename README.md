## Live API Deployment

The CSE341 Books API is deployed on Render.

**Base URL:** https://cse341-books-mhb8.onrender.com

### Available Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/books` | Retrieve all books |
| GET | `/books/:id` | Retrieve a book by ID |

### Example Requests

- https://cse341-books-mhb8.onrender.com/books
- https://cse341-books-mhb8.onrender.com/books/b1
